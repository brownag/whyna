# whyna: Informative Missingness via vctrs Records

Implements typed/informative missingness following Rubin's MCAR/MAR/MNAR
framework. Tracks why values are missing using a vctrs record vector
with 'value' and 'type' fields. Integrates cleanly with tibble, dplyr,
and base R idioms.
